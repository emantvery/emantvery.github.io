NOTE 01

挂号接口：从业务状态到测试用例

业务流程、状态机、场景矩阵、重复请求与多层断言。适合从功能测试过渡到接口测试时阅读。

↗ NOTE 02

用 pytest 搭一组可复现的接口测试

提供独立演示服务与测试代码，解释 fixture、参数化、请求超时、数据隔离和 CI。

↗ NOTE 03

AI 导诊类产品应该分层测什么

把传统接口可靠性、输出约束、页面兜底与内容评估拆开，避免用一个“返回 200”概括质量。

↗ NOTE 04

从稳定定位到页面冒烟检查

用可运行的 Playwright 示例检查本站文章入口、移动端菜单和主题切换，解释稳定定位与自动等待。

↗ NOTE 05

接口成功后，数据库该怎么核对

从预约与号源的业务不变量出发，用 SQL 找出不一致状态，附可运行 SQLite 示例。
