# SQL 状态核对示例

这是使用 Python 标准库 SQLite 写的**独立教学示例**。不连接云脑诊疗平台，也不反映原项目的真实表结构、业务规则或测试结果。运行：

```bash
python check.py
```

示例把“总号源 = 剩余号源 + 有效预约数”当作教学规则，验证一致状态无异常行、不一致状态被 SQL 查出。取消的预约不计入有效预约。真实系统可能还有待支付占用、超时释放、分时段库存和并发事务，不能直接复制此公式；先确认业务口径，再写核对 SQL。
